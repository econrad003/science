Axiom candidates for many-valued algebras.

DESCRIPTION

    Axioms in group 1 (i.e. 1.1 through 1.5) are basic statements
  about (material) implication and negation.  Group 2 refines negation.
  Groups 3 and 4 deal with disjunction and conjunction.  Group 5 deals
  (material) equivalence.  Group 6 includes several distributive laws.
  Group 7 includes several candidates for definitions, expressed as
  equivalences.  Group 8 includes some more obscure axioms (all classically
  valid, of course) which help to differentiate the systems.

    These axioms characterize the two-valued propositional calculus, but
    are not independent.

RULES

  MP: If ⊢(p⊃q) and ⊢p, then ⊢q.                                   modus ponens
  RC: If ⊢(p⊃q) and ⊢(q⊃q), then ⊢(p⊃q).                 hypothetical syllogism
  RK: If ⊢p and ⊢q, then ⊢(p∧q).                                     adjunction

REMARKS

  Proposition 2.6 is satisfied in Ł₃ and CPC but fails in the
  remaining examples. In particular, it distingishes the three-
  valued Łukasiewicz algebra from Łukasiewicz algebras with more
  values

  It is possible to define expressions in the finitely many-valued
  Łukasiewicz algebras which have the value 1 (displayed here as T)
  when and only when the variable has a specfic value.  For
  example, look at a partial truth table for 'p≡~p' in the
  infinite-valued algebra Ł(ℚ∩[0,1]}):
           p       ~p      p≡~p
       ---------------------------
           0        1       0
          ...      ...     ...     increasing in (0,1/2)
          1/4      3/4     1/2
          ...      ...     ...     increasing in (1/2,1)
          1/2      1/2      1
          ...      ...     ...     decreasing in (1/2,1)
          1/4      3/4     1/2
          ...      ...     ...     decreasing in (0,1/2)
           1        0       0
  This expression has the value 1 when and only when |p|=1/2.
  Moreover, it only takes on classical values (0 or 1) when
  |p|=0 or 1/2 or 1.  If we subtitute this expression for 'p' into
  a classical tautology which fails at |p|=1/2, we get statement
  which is valid in Ł₃ but not valid in Ł₅ or in algebras that
  contain 1/4 as a truth value.  (It the tautology fails
  elsewhere, e.g. |p|=1/3 or |p|=2/3, then the resulting expression
  will likewise fail at one of those values.

  We can iterate this idea. Substituting 'p≡~p' for 'p' in 'p≡~p'
  yields '(p≡~p)≡~(p≡~p)' which is true when |p|=1/4 or 3/4 and
  false when |p|=0 or 1/2 or 1.  Subtituting this expression for
  'p' into a classical tautology which fails at |p|=1/2 gives us
  a statement which is true in both Ł₃ and Ł₅, but fails in Ł₉.

  Proposition 1.4, the importation axiom, is important for proving
  the Deduction theorem in the classical propositional calculus.
  Both are valid in the Gödel-Dummett algebras as well as in the.
  intuistionistic propositional calculus.  Neither are not valid in
  the many-valued Łukasiewicz algebras.

  Proposition 2.1 is valid in the Gödel-Dummett algebras, but
  proposition 2.2 is not.  Neither is valid in the any-valued
  Łukasiewicz algebras.

  Disjunction can be defined in terms of implication using
  formula 7.2 in all of the Łukasiewicz algebras. There is no
  general way of defining disunction in terms of negation and
  Gödel-Dummett algebras, nor is there a general way of defining
  implication in terms of disjunction and negation in those
  same algebras.  Formula 7.1 is not valid in any of the many-
  valued logics in either family.  DeMorgan's Law fails in the
  Gödel-Dummett algebras.  The operators {'~', '∨', `∧', '⊃'}
  form a functionally independent set in the Gödel-Dummett
  algebras.
