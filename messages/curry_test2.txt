    definitions:

        D7. 0 = |KI.

    We define ℕ as inductively as a subset of 𝕮:

        N1. 0 is in ℕ.
        N2. If n is in ℕ, then |Sn is in ℕ.

    derived finitely by applying Rules N1 and N2.

ADDITION

    There are many entities which could be used as definitions
    of addition.  One such operator is + = ||BAD.  We start with a few
    examples.

3 + 5 = 8 = 5 + 3:                    (commutativity)
	||||+35ab = ||||||BAD35ab = |a|a|a|a|a|a|a|ab
	||8ab = |a|a|a|a|a|a|a|ab
	||||+53ab ||||||BAD53ab = |a|a|a|a|a|a|a|ab

(1 + 3) + 5 = 9 = 1 + (3 + 5):        (associativity)
	||||+||+I35ab = ||||||BAD||||BADI35ab = |a|a|a|a|a|a|a|a|ab
	||9ab = |a|a|a|a|a|a|a|a|ab
	||||+I||+35 = ||||||BADI||||BAD35ab = |a|a|a|a|a|a|a|a|ab

    To verify that ||BAD is a correct implementation of addition,
    we need to check that it works for all members of ℕ. An addition
    operator in CL should satisfy the following requirements:

        If m and n are members of ℕ, then:
            add1. 0+n = n; and
            add2. (m+1)+n = (m+n)+1.

    In fact ||BAD works very nicely as we can show it satisfies
    both conditions for all m and n in 𝕮.

add1. If n is a member of ℕ, then ||+0n = n.
  or: If n is a member of ℕ, then ||||BAD0n = n.
LHS: ||||||BAD0nab
  1: ||||A|D0nab                                  B
  2: ||||D0a|nab                                  A
  3: ||0a||nab                                    D
  4: ||nab                                        0

    In fact, ||||BAD0n = n for every n in 𝕮.

add2. If m and n are members of ℕ, then ||+|Smn = |S||+mn.
  or: If m and n are members of ℕ, then ||||BAD|Smn = |S||||BADmn.
LHS: ||||||BAD|Smnab
  1: ||||A|D|Smnab                                B
  2: ||||D|Sma|nab                                A
  3: |||Sma||nab                                  D
  4: |a||ma||nab                                  S
RHS: |||S||||BADmnab
  1: |a||||||BADmnab                              S
  2: |a||||A|Dmnab                                B
  3: |a||||Dma|nab                                A
  4: |a||ma||nab                                  D

    Let's prove some basic facts about addition (using ||BAD)...

TN3. (Identity) If m is in ℕ, then 0+m = m = m+0.
LHS: ||||||BAD0mab

TN6. (Commutativity) If m and n are in ℕ, then m+n = n+m.
  By induction on m...
    True for m=0 and all n by TN3.

  To prove: ||||BAD|Smn = ||||BADn|Sm

   = ||||BADn||||BADmI        by associativity
   = ||||BADnSm        by TN4.  Q.E.D.

RHS: ||||Bnmab
  1: ||n|mab                                                            B
  Then ||m|nab = ||n|mab.

  We want to verify that:
      ||.|Smn = ||.n|Sm.
LHS: ||.Smn           i.e. ||((1+m)n)ab
LHS: ||||B|Smnab
  1: |||Sm|nab                                                          B
  2: ||na||m|nab                                                        S
   = ||na||n|mab, by the induction hypothesis
MHS: ||||.n||+Imab     i.e.: ||(n(1+m))ab
  = ||||||BAD||BnI||Bnmab
  1: ||||A|D||BnI||Bnmab                                                B
  2: ||||D||BnIa|||Bnmab                                                A
  3: ||||BnIa||||Bnmab                                                  D
  4: ||n|Ia||||Bnmab                                                    B
  5: ||na||||Bnmab                                                      I
  6: ||na||n|mab                                                        B
RHS: ||||.n|Sm         i.e.: ||(n(1+m))ab
  = ||||Bn|Smab
  1: ||n||Smab                                                          B
LHS = MHS, by reduction.
MHS = RHS, by the right successor property (TN12).

    Note that both equalities are valid for ℕ, but not for 𝕮.
